# Maintenance Lab Artifacts (Bezier Tool)

This folder contains small, exam-ready artifacts that map the Bezier tool maintenance work
to the laboratory exercises:

- `ChangeRequest.md` – User story + acceptance criteria
- `ConceptLocation.md` – Concept location notes + domain class table
- `ImpactAnalysis.md` – Impact analysis notes + package impact table
- `Refactoring.md` – Code smells + refactoring strategy + patterns
- `Actualization.md` – How the changes relate to SOLID/Clean Code
- `BDDScenarios.md` – Given/When/Then scenarios derived from the user story

The code changes themselves are in `jhotdraw-core`.
